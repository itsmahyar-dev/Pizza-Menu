# Pizza Menu

A responsive pizza menu website built with **React, JavaScript, and CSS**.

## Features

* Display pizza items with images, names, descriptions, and prices
* Reusable React components
* Dynamic rendering of pizza items
* Conditional rendering for sold-out pizzas
* Responsive design
* Clean and modern user interface
* Custom CSS styling

## Technologies

* HTML5
* CSS3
* JavaScript (ES6+)
* React
* Create React App
* Git & GitHub
* GitHub Pages

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/itsmahyar-dev/Pizza-Menu.git
cd Pizza-Menu
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm start
```

The application will be available at:

```text
http://localhost:3000
```
